How Merkle trees work

A Merkle tree summarises every transaction in a block with one hash, the Merkle root. It is a compact commitment that lets anyone check membership cheaply.

Building the tree

Each transaction is hashed. Neighbouring hashes are paired, joined and hashed again, level by level, until one hash is left. If a level has an odd number of hashes, the last one is duplicated.

  • Leaves are transaction hashes.
  • The root sits in the block header.

Proving inclusion

A Merkle path is the list of sibling hashes from a transaction up to the root. A light client rehashes up the path and compares the result with the root in its header.
